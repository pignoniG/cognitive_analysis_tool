Calibration Sequence Tool

Show a full-field colour sequence on a screen or in a VR headset, build and scramble your own sequences, and log every run to CSV. Made for the participant calibration of the Cognitive Workload Tool. Everything runs in this page; nothing is uploaded.

1. Sequence

Drag a block to reorder it, drag its right edge to change its length (0.5 s steps, hold Alt for 0.1 s). With a block selected: ←→ select, Alt+←→ move, +− length, Del remove.

2. Run

Order for this run
Before you start
  • Fix the display: constant brightness (no auto-brightness, night shift or adaptive contrast), sRGB profile, HDR off. Sequence colours are sent as plain sRGB values; the actual light depends on the display.
  • On screen the field fills the whole window in full screen; Esc aborts. The cursor is hidden.
  • In VR the participant sits at the centre of a sphere painted in one colour, on a headset browser or a desktop browser with a WebXR runtime (SteamVR, Varjo Base, …). The page must be served over HTTPS or from localhost. Control the run from the desktop window; the participant can start it with the trigger.
  • Timings are logged per frame: time is when the frame carrying the new colour was submitted; the display adds a fixed delay of about one frame.
